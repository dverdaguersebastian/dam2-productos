Sobre nosotros

DAM2 Productos es una aplicación de ejemplo desarrollada como actividad guiada para la asignatura de Desarrollo de Interfaces (DAM2). Nuestro objetivo es mostrar, de forma práctica, cómo construir una aplicación Ionic + Angular Standalone capaz de consumir una API REST real y presentar sus datos de forma clara y accesible.

Este proyecto ha sido creado con fines educativos, aplicando buenas prácticas de Angular moderno: componentes Standalone, control de flujo con @if/@for, signals y rutas lazy-loaded.
